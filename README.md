# Requirements
This addon needs either [pfQuest](https://github.com/shagu/pfQuest) or [Questie-octo](https://github.com/SandreaSub/Questie-Octo)

# Install
Download the [zip](https://github.com/papgergo/QuestPlatesOcto/archive/refs/heads/main.zip), extract the folder into Interface/AddOns/ and remove "-main" from the folder name.
